# Roster Manager for Home Assistant

Home Assistant app (formerly "add-on") that captures a Virgin Australia Sabre roster on demand, reviews it, syncs it to Google Calendar and backs it up to Google Drive.

**Install:** Settings → Apps → App Store → ⋮ → Repositories → add `https://github.com/Tuttle13/roster-manager-ha` → install **Roster Manager** → Start, and turn on *Show in sidebar*.

See `roster_manager/DOCS.md` for setup.
